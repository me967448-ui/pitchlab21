PITCHLAB 21 - FIRST RUN
=======================

1. RIGHT-CLICK the downloaded ZIP and choose Extract All. Do not run BAT files while they are still inside the ZIP preview.
2. Open the extracted pitchlab21 folder.
3. Double-click START-PITCHLAB.bat. Keep its black terminal window open while using the site.
4. If the site opens but remains on the startup screen, read the visible diagnostic error.
5. If the server cannot start for any reason, double-click OPEN-LOCAL-FILE.bat to open the bundled page in your browser. Direct-file mode has limited catalogue-sync features.

The home page starts with a small sample. The full PESMASTER player list loads only when you open Players, Compare, Teams, Leagues, a player/team page, or Squad Builder. Team and coach/tactics files are also loaded only when you enter their sections.

If START-PITCHLAB.bat prints a URL (such as http://127.0.0.1:8001/), copy that exact URL into Chrome. Never assume port 8000 is the correct one.
